**Evidence directory**

`handoff-validation.json` records the observed documentation/fixture verification performed while preparing this repository. It verifies consistency, golden arithmetic, selected local links, reference-script syntax, Git origin and ignore patterns. It does not prove application behavior, browser layout, model quality or provider integration.

Application work must create scoped reports under `phase-01/` through `phase-12/` following `../VALIDATION.md`. Never copy a passing result to a different revision or claim unexecuted commands passed. Keep raw logs with possible secrets/private data under the ignored `raw/` directory, and commit only sanitized necessary reports.
