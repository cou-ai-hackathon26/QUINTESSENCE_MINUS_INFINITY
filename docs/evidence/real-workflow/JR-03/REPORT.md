# Actual agent work, hybrid retrieval and reviewed proposals

23 November 2026. JR-03 extends the existing app; it preserves JR-01/02 and the approved UI.

The coordinator uses explicit routing, creates persistent queued tasks and returns HTTP 202. A background worker with its own database session executes an evidence reader, the actual deterministic reconciliation tool, an independent skeptic and a report writer. Three real model requests are counted independently from tool work. Public source packs, task status transitions, results and actual provider receipts drive polling and animation. Replay remains explicitly replay. The skeptic receives originals and deterministic results independently of the evidence reader's narrative. These tasks execute sequentially; the interface does not claim simultaneous model work.

Actual live verification found that an earlier model answer incorrectly called a confirmed false inclusion flag unknown. That observation is retained as `initial-quality-observation.json`, explicitly unsuccessful for quality. The final implementation validates typed case flags, payable alternatives and quoted source text; unsupported changes fail closed. The final actual run correctly preserves return_included=false, payment_included=null and payable alternatives 1,800,000 / 2,200,000 paisa. This is not a claim that arbitrary model prose is infallible.

Merchant memory now performs real local multilingual E5 inference, Unicode-aware BM25 keyword scoring and RRF. Original official model weights are pinned to a revision and SHA-256 checked before loading. No request-time download occurs. Old hash vectors are ignored and the hash generator was removed. Query/document model identity must match. Tenant and revocation filters run before scoring; explicit invoice IDs retain priority. A missing model yields disclosed keyword-only mode. Similarity threshold 0.78 is an initial retrieval filter, not a correctness or evidence-support score. This is a bounded application search implementation, not a measured large-corpus production index.

The actual local model correctly ranks the return policy first for independent Bangla and English paraphrases. Evidence contains the model artifact identity, real similarity scores and timings in `semantic-model.json`, `semantic-inference.json` and `actual-agent-retrieval.json`. Preparation: `node scripts/run-python.js scripts/setup-semantic-model.py`, then `SEMANTIC_ENABLED=true` in ignored local `.env`. Official model/card: https://huggingface.co/intfloat/multilingual-e5-small . Runtime documentation: https://qdrant.github.io/fastembed/ . FastEmbed 0.9.1 / ONNX Runtime 1.32.0 CPU are installed locally. Weights and tokenizer remain ignored under `apps/api/data/models/`.

Voice and chat proposals link to a review page. The owner selects the registered party, verifies amount/account and explicitly confirms. Supported internal records: cash sale, credit sale, old-debt collection, expense and supplier-payment bookkeeping. A unique source-operation event, audit fingerprint, balanced integer-paisa postings, atomic balance changes and compare-and-update party dues prevent duplicate posting and overdraw. The actual file-backed SQLite race test sends two simultaneous requests and observes one entry plus one replay. Other transaction APIs are not covered by this specific guarantee; their repair belongs to JR-04. No funds are transferred externally, no customer is messaged and stock items/cost are not invented from an unlinked total.

Case evidence support uses the existing versioned policy, never model self-ratings or semantic similarity. Stale case versions hide the old support assessment and generated summary. Cancellation rejects in-flight findings; finished history cannot be relabeled cancelled. Provider failure, exhausted model budget, invalid citations and inconsistent case facts are recorded failures rather than canned success.
