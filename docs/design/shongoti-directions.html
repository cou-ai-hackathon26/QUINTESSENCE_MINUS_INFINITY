উদাহরণ ২ · পেমেন্ট ও return

এই bill-এর জন্য ৪,০০০ টাকা দেওয়া হয়েছে। ৩,০০০ টাকার return credit supplier মেনেছে এবং তা বর্তমান দাবিতে এখনো কাটেনি। পেমেন্ট আগেই কাটা হয়েছে কি না আপনার উপরের নির্বাচনে নির্ধারিত হয়।

ডেমো support index কীভাবে বদলায়?

পাঁচটি সমান critical claim-এর চারটি শুরুতে supported: base ৮০, কিন্তু গুরুত্বপূর্ণ inclusion তথ্য অজানা বলে policy cap ৫৯। উত্তর দিলে পাঁচটি claim-ই এই উদাহরণে supported হয়: index ১০০। এটি মডেলের সঠিক হওয়ার probability নয়; approval ছাড়া কোনো action execute হয় না।
